# Generic 3D Printer Control / 通用 3D 打印机控制

Send G-code to any Marlin/RepRap-style 3D printer over TCP or serial. This skill provides the generic communication layer, safety framework, and error handling.

通过 TCP 或串口向任何使用 Marlin/RepRap 风格协议的 3D 打印机发送 G-code。本 skill 提供通用通信层、安全框架和异常处理。

## Initial Handshake / 初次握手

When connecting to a new printer or starting a new session, you should first run:
```bash
python3 /opt/data/skills/make/3d-printer/scripts/printer_read.py status --json
```
This provides the baseline state (current temp, position, endstops) to ensure the printer is ready.

## Safety Tiers / 安全权限分级

You must follow this tiered safety system to prevent hardware damage or fire.

你必须遵守以下安全分级以防火防灾：

### 🔴 Level 2: High Risk (Requires User Clarification ONCE)
You **MUST** use the `Clarify` tool to get explicit user confirmation before executing these actions **ONCE per user request**. Do NOT loop the confirmation.
*   **Heating**: Any `heat` command (hotend or bed).
*   **Printing**: Starting `printer_print.py`. (Printing is high-risk).
*   **EEPROM/Factory Reset**: `passthrough "M500"` or `passthrough "M502"`.

### 🟡 Level 1: Medium Risk (Script Enforced)
*   **Extrude/Retract**: `extrude`. The script will automatically block if hotend < 170°C.

### 🟢 Level 0: Safe (Execute Directly)
*   **All Queries**: `printer_read.py status`, `info`, `progress`, `bounds`.
*   **Movement**: `move`. The script enforces `--max-x`, `--max-y`, `--max-z` bounds automatically from `.env`.
*   **Stopping**: `cool` (turn off heaters), `estop` (M112).
*   **Generating G-code**: Running `printer_draw.py` is safe, as it only creates a file on the disk.

### 3. Generate Basic Geometry / 生成基础几何体 G-code
When the user asks to draw or print ANY shape, you MUST use `printer_draw.py`. DO NOT calculate coordinates manually. DO NOT piece together multiple `line` commands. The script natively supports ALL shapes below.

当用户要求画图或打印任何形状时，你**必须**使用 `printer_draw.py`。**绝对禁止**自己计算坐标，**绝对禁止**用多个 `line` 拼凑图形。脚本原生支持以下所有形状：

**Supported Shapes & Parameters / 支持的形状与参数:**
- `line`: `--x1 110 --y1 110 --x2 160 --y2 160`
- `triangle` (equilateral): `--size 30`
- `rectangle`: `--w 40 --h 20`
- `circle`: `--diameter 50`
- `ellipse`: `--rx 30 --ry 10`
- `polygon` (regular): `--sides 6 --size 30`
- `ring` (2D flat): `--diameter 50 --inner_diameter 30`
- `cube` (3D equal sides): `--size 20 --height 20 --infill 20`
- `cuboid` (3D rectangular box, different L/W): `--w 40 --d 30 --height 60 --infill 20`
- `cylinder` (3D): `--diameter 30 --height 15`
- `pyramid` (3D): `--size 40 --height 20`
- `sphere` (3D): `--diameter 40`
- `cone` (3D): `--diameter 40 --height 30`
- `ellipsoid` (3D): `--diameter 40 --height 60`

**Intent Mapping / 意图映射:**
- If the user requests a **"hollow" (空心)** or **"shell"** or **"outline only"** shape, you MUST pass the `--hollow` flag.
- 如果用户要求画**“空心”**或**“仅轮廓”**的图形，你**必须**使用 `--hollow` 参数。
- If the user requests a **"solid" (实心)** shape, you MUST pass `--infill 100`.
- 如果用户要求画**“实心”**图形，你**必须**传入 `--infill 100`。
- If the user specifies a custom infill percentage (e.g., "50% infill"), pass `--infill 50`.
- 如果用户指定了自定义填充率（如“50% 填充”），传入 `--infill 50`。
- If the user requests a rectangular box with **different length and width**, you MUST use `cuboid` instead of `cube`.
- 如果用户要求打印**长宽不相同**的长方体（如长 40 宽 30），你**必须**使用 `cuboid`，而不是 `cube`。

**CRITICAL: SMART SUPPORT / 极度重要：智能支撑**
The script natively supports **smart overhang detection** and is enabled by default. You **DO NOT** need to pass any `--support` flag. It automatically adds supports to `sphere` and `ellipsoid` bottoms, while keeping `cube` and `pyramid` support-free. If the user explicitly says **"不要支撑" (no support)**, you MUST pass `--no-support`.
脚本原生内置了**智能悬垂检测**，且**默认开启**。你**完全不需要**传递 `--support` 参数。它会在球体和椭球体的底部自动生成支撑，而立方体等不会。如果用户明确要求**“不要支撑”**，你**必须**传入 `--no-support` 参数。

**Examples / 示例**:
```bash
# Generate a triangle (size 30)
python3 /opt/data/skills/make/3d-printer/scripts/printer_draw.py triangle --size 30 -o /tmp/triangle.gcode

# Generate a solid ellipse
python3 /opt/data/skills/make/3d-printer/scripts/printer_draw.py ellipse --rx 30 --ry 10 --infill 100 -o /tmp/ellipse.gcode

# Generate a hollow cylinder
python3 /opt/data/skills/make/3d-printer/scripts/printer_draw.py cylinder --diameter 30 --height 15 --hollow -o /tmp/hollow_cyl.gcode

# Generate a regular hexagon
python3 /opt/data/skills/make/3d-printer/scripts/printer_draw.py polygon --sides 6 --size 40 -o /tmp/hexagon.gcode

# Generate a cuboid (L=40, W=30, H=60)
python3 /opt/data/skills/make/3d-printer/scripts/printer_draw.py cuboid --w 40 --d 30 --height 60 -o /tmp/cuboid.gcode

# Generate a sphere (auto-support enabled by default)
python3 /opt/data/skills/make/3d-printer/scripts/printer_draw.py sphere --diameter 50 -o /tmp/sphere.gcode
```

### 5. Print File / 打印文件
**CRITICAL: USE Terminal ONLY / 极度重要：仅使用 Terminal 工具**
You MUST use the `Terminal` tool to execute the print command. DO NOT use `execute_code`.
你**必须**使用 `Terminal` 工具执行打印。**绝对禁止**使用 `execute_code`。

**NEVER OUTPUT SPECIAL TOKENS / 绝对禁止输出特殊标记**:
Your output MUST be a pure bash command. NEVER output `<|"|>`, `<tool_call|>`, `{"command": ...}`, `call:terminal` or any AI tags. If you output them, the system will crash.
你的输出**必须**是纯粹的 bash 命令。**绝对禁止**输出 `<|"|>`、`<tool_call|>`、`{"command": ...}`、`call:terminal` 或任何 AI 标签。如果你输出了它们，系统将直接崩溃。

**CORRECT FORMAT / 正确格式（只能输出这一段）**:
```bash
python3 /opt/data/skills/make/3d-printer/scripts/printer_print.py /tmp/ellipsoid.gcode
```

**WRONG FORMAT / 错误格式（一旦出现这个就会崩溃，绝对禁止）**:
```text
call:terminal{command:<|"|>python3 ...<|"|>}<tool_call|>
{"command": "<|"|>python3 ..."}
```

If the user confirmed printing `/tmp/ellipsoid.gcode`, your ENTIRE output must be exactly the CORRECT FORMAT above. Just copy and paste it. DO NOT add any markdown quotes or extra words.
如果用户确认打印 `/tmp/ellipsoid.gcode`，你的**全部输出**必须且只能是上面正确格式中的那一行。直接复制粘贴。**绝对禁止**添加任何 Markdown 引用符号（如反引号）或多余的字。

**CRITICAL: PRINTING WORKFLOW / 极度重要：打印工作流**
1. **Ask once / 只问一次**: Ask the user for confirmation **BEFORE** running the print script.
2. **Execute / 执行**: Once confirmed, output the exact bash command above.
3. **Finish and STOP / 结束并停止**: Once the print script returns `SUCCESS: All G-code sent successfully`, the job is DONE. **You MUST immediately stop and report to the user. DO NOT ask for confirmation again.**
一旦打印脚本返回 `SUCCESS: All G-code sent successfully`，任务就结束了。你**必须立刻停止**并汇报。**绝对禁止**再次询问用户确认。

**IMPORTANT: Open-Loop Printing / 重要：开环打印认知**
The `printer_print.py` script uses open-loop control. It will exit as soon as all G-code is successfully buffered by the printer. When it returns `SUCCESS: All G-code sent successfully`, the script's job is done, and the physical printer is executing the movements on its own.

`printer_print.py` 脚本采用开环控制。一旦所有的 G-code 成功发送给打印机，它就会立刻退出。当终端返回 `SUCCESS: All G-code sent successfully` 时，代表脚本的任务已结束，物理打印机正在自行执行这些动作。

**CRITICAL / 极度重要**:
You **MUST NOT** report "打印物理完成 (Print physically finished)". Instead, you must tell the user: "G-code 文件已成功发送，打印机正在后台物理打印中 (G-code sent successfully, printer is now printing)."
你**绝对禁止**向用户报告“打印物理完成”。你必须告诉用户：“**G-code 文件已成功发送，打印机正在后台物理打印中**”。

**NEVER RETRY AUTOMATICALLY / 绝对禁止自动重试**:
If the print command fails or times out, you MUST STOP and report the error. DO NOT attempt to run the print script again automatically.
如果打印命令失败或超时，你**必须立刻停止**并报告错误。**绝对禁止**自动重新运行打印脚本。
